# EPL 승부예측 게임 — 설계 (디미고 입시학원 과제)

날짜: 2026-07-24 밤 / 제출: 2026-07-25 오전
대상: 예준 (중3, 코딩 기초) — 아빠가 먼저 만들고 가이드 문서로 전달

## 목표

EPL 경기 결과를 예측하고 친구들과 점수 경쟁하는 웹앱.
배포 없이 브라우저에서 HTML 파일을 직접 여는 방식.
보안 과제("점수 조작 막기")는 조작 시연 + 해결 방향 문서화로 커버.

## 범위

**포함**: 이름 입력, 경기 10개 승무패 예측, 채점(+3점/적중), localStorage 랭킹, 조작 시연 가이드
**제외**: 서버, 로그인, 배포, 프레임워크, 빌드 도구

## 파일 구조

```
epl-predict/
├── index.html   ← 화면 뼈대 (섹션 3개: 이름 입력 / 경기 카드 / 결과+랭킹)
├── style.css    ← 스타일
├── data.js      ← 24-25 시즌 EPL 종료 경기 10개 (openfootball 기반, JS 변수로 내장)
└── app.js       ← 예측 선택, 채점, 랭킹 저장/표시
```

- 데이터를 fetch 대신 `data.js` 변수로 내장: file:// 환경 CORS 오류 회피 (중3 디버깅 함정 제거)

## 게임 흐름

1. 이름 입력 → 시작 버튼
2. 경기 카드 10개 — [홈승 / 무 / 원정승] 3버튼 중 택1
3. "채점하기" → 실제 결과와 비교, 적중당 +3점
4. 내 점수 표시 + 랭킹 표 (localStorage 누적 — 같은 컴퓨터에서 여러 명 플레이 시 랭킹 쌓임)

## 데이터 형태 (data.js)

```js
const MATCHES = [
  { home: "아스날", away: "맨시티", homeScore: 2, awayScore: 1 },
  // ... 총 10경기, 이미 종료된 경기라 즉시 채점 가능
];
```

## 보안 과제 시연 (제출 스토리)

1. F12 → Application → localStorage에서 점수를 999로 직접 수정
2. 새로고침 → 랭킹 1위 조작 확인
3. 결론: "채점과 저장을 사용자 브라우저에서 하면 조작 가능 → 실제 서비스는 서버가 예측만 받고 채점은 서버에서" (app.js 주석 + 가이드 문서에 명시)

## 산출물

1. `epl-predict/` 앱 4파일
2. `epl-predict/GUIDE.md` — 예준이용: 코드 라인별 설명, 따라 만들기 순서(빈 파일부터 4단계), 조작 시연 방법, 제출 시 말할 포인트

## 에러 처리

- 이름 미입력 시 시작 불가 (알림)
- 10경기 전부 선택해야 채점 버튼 활성화
- localStorage 파싱 실패 시 빈 랭킹으로 초기화

## 테스트

- 브라우저에서 index.html 열기 → 전체 플로우 수동 확인
- 조작 시연 재현 확인
- 모바일 폭(375px)에서도 카드 레이아웃 유지 확인
