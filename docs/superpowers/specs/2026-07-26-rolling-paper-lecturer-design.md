# 롤링페이퍼: 전승기 강사님 응원 메시지

## 목적
첫 강의를 성공적으로 마친 전승기 강사님께 수강생들이 익명(또는 이름) 응원·감사 메시지를 남기는 웹페이지. 서버/빌드 없이 `index.html`을 더블클릭해서 바로 열 수 있어야 하며, Supabase를 통해 메시지가 새로고침 후에도 유지되고 링크를 공유받은 다른 사람도 같은 메시지 목록을 볼 수 있어야 한다.

## 카피
- 제목: "전승기 강사님, 축하합니다!"
- 부제: "전승기를 만나면 전성기가 옵니다!!"

## 파일 구조
- 새 독립 폴더 `rolling-paper/` (기존 Next.js 레스토랑 프로젝트와 무관한 별개 산출물이므로 루트에 분리)
- `rolling-paper/index.html` — 진입점, 더블클릭으로 실행
- `rolling-paper/style.css` — 스타일
- `rolling-paper/app.js` — Supabase 연동 및 렌더 로직
- Supabase JS는 CDN(`https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2`)으로 로드. 빌드 도구 없음.
- `app.js` 상단에 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 상수로 분리 — Supabase 프로젝트 생성 후 값만 교체하면 됨.

## 데이터 모델 (Supabase)
테이블 `messages`:
| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid, PK, default gen_random_uuid() | |
| name | text, nullable | 비우면 "익명"으로 표시 |
| message | text, not null | |
| created_at | timestamptz, default now() | |

RLS: anon 키로 insert/select 가능하도록 정책 설정 (공개 롤링페이퍼이므로 인증 없이 열람/작성 허용).

## 데이터 흐름
1. 페이지 로드 → `messages` 테이블을 `created_at` 오름차순으로 전체 조회 → 카드 그리드로 렌더
2. 사용자가 이름(선택) + 메시지(필수) 입력 후 등록 버튼 클릭 → Supabase insert
3. insert 성공 시: 폼 초기화 + 새 카드를 화면에 즉시 추가 (재조회 없이 로컬 append)
4. 실시간 동기화(다른 사용자의 새 메시지가 새로고침 없이 반영)는 범위 밖 — 새로고침 시 최신 목록이 보이는 것으로 충분

## 화면 구성
- **헤더**: 제목 + 부제 (위 카피)
- **입력 폼**: 이름 input(placeholder "익명"), 메시지 textarea(필수), 등록 버튼
- **메시지 월**: 카드 그리드. 각 카드 = 이름 + 메시지 + 등록 시간(상대 시간 또는 날짜)
- **빈 상태**: 메시지가 하나도 없을 때 "첫 메시지를 남겨보세요" 안내 문구

## 비주얼 디자인
사용자가 별도로 레퍼런스 이미지를 전달할 예정 — 컬러/타이포/톤은 이미지 수신 후 확정. 이번 스펙은 구조·데이터 흐름·컴포넌트 구성까지만 다룸. 레이아웃(그리드 카드형 메시지 월, 상단 입력 폼)은 이미지와 무관하게 고정된 골격으로 유지.

## 에러 처리
- 메시지가 빈 값이면 등록 버튼 클릭 시 제출 차단 + 인라인 안내
- Supabase 연결/insert 실패 시 화면에 에러 메시지 노출 (예: "메시지 등록에 실패했습니다. 다시 시도해주세요.")
- 최초 조회 실패 시(네트워크 문제 등) 안내 문구 표시

## 테스트 방법
- 로컬에서 `index.html` 직접 열어 등록 → 새로고침 → 메시지 유지 확인
- 두 개의 브라우저 탭(또는 다른 브라우저)에서 각각 열어, 한쪽에서 등록한 메시지가 다른 쪽 새로고침 후 보이는지 확인 (공유 시나리오 검증)
- 이름 비운 채 등록 시 "익명"으로 표시되는지 확인
- 빈 메시지로 등록 시도 시 차단되는지 확인

## 배포 및 설치
- 순수 정적 파일(서버·env 불필요, Supabase URL/anon key는 공개 가능한 클라이언트 키라 코드에 직접 포함)이므로 Netlify Drop(`netlify.com/drop`)에 `rolling-paper/` 폴더를 드래그하는 것만으로 배포 가능
- 폰 홈 화면에 "앱처럼" 설치(주소창 없이 열림)되도록:
  - `manifest.json` 추가 (`display: standalone`, `name`, `start_url`, 기본 아이콘)
  - `index.html`에 `apple-mobile-web-app-capable`, `apple-touch-icon`, `theme-color` 메타태그 추가 (iOS 홈 화면 추가 대응)
  - 커스텀 아이콘 이미지는 비주얼 디자인(컬러) 확정 후 제작 — v1은 브라우저 기본 아이콘으로 설치 가능한 상태만 보장

## 범위 밖 (v1 제외)
- 실시간 푸시 동기화
- 메시지 삭제/수정, 관리자 화면
- 로그인/인증
- 카드 배경색 랜덤화 등 장식 옵션 (필요 시 추후 추가)
