# 롤링페이퍼: 전승기 강사님 응원 메시지

## 목적
첫 강의를 성공적으로 마친 전승기 강사님께 수강생들이 익명(또는 이름) 응원·감사 메시지를 남기는 웹페이지. 서버/빌드 없이 `index.html`을 더블클릭해서 바로 열 수 있어야 하며, Supabase를 통해 메시지가 새로고침 후에도 유지되고 링크를 공유받은 다른 사람도 같은 메시지 목록을 볼 수 있어야 한다.

## 카피
- 제목: "전승기 강사님, 축하합니다!"
- 부제: "전승기를 만나면 전성기가 옵니다!!"

## 파일 구조
- 새 독립 폴더 `rolling-paper/` (기존 Next.js 레스토랑 프로젝트와 무관한 별개 산출물이므로 루트에 분리)
- `rolling-paper/index.html` — 진입점, 더블클릭으로 실행
- `rolling-paper/style.css` — 스타일
- `rolling-paper/app.js` — Supabase 연동 및 렌더 로직
- Supabase JS는 CDN(`https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2`)으로 로드. 빌드 도구 없음.
- `app.js` 상단에 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 상수로 분리 — Supabase 프로젝트 생성 후 값만 교체하면 됨.

## 데이터 모델 (Supabase)
테이블 `messages`:
| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid, PK, default gen_random_uuid() | |
| name | text, nullable | 비우면 "익명"으로 표시 |
| message | text, not null | |
| created_at | timestamptz, default now() | |

RLS: anon 키로 insert/select 가능하도록 정책 설정 (공개 롤링페이퍼이므로 인증 없이 열람/작성 허용).

## 데이터 흐름
1. 페이지 로드 → `messages` 테이블을 `created_at` 내림차순(최신순)으로 전체 조회 → 카드 그리드로 렌더
2. 사용자가 이름(선택) + 메시지(필수) 입력 후 등록 버튼 클릭 → Supabase insert
3. insert 성공 시: 폼 초기화 + 새 카드를 메시지 월 맨 위(최신순 유지)에 fade-in으로 추가 (재조회 없이 로컬 prepend)
4. 실시간 동기화(다른 사용자의 새 메시지가 새로고침 없이 반영)는 범위 밖 — 새로고침 시 최신 목록이 보이는 것으로 충분

## 화면 구성
레퍼런스 구조(레이아웃만 차용, 컬러는 블랙+크림 유지):

- **히어로**: 작은 상단 라벨(대문자 트래킹) + 큰 볼드 타이틀 "전승기 강사님, 축하합니다!" + 서브텍스트 "전승기를 만나면 전성기가 옵니다!!" + 안내문 "따뜻한 한마디를 남겨보세요"
- **입력 폼 카드** (블랙 보더 박스):
  - 좌측 상단 라벨 "FROM. 마음을 전하는 사람"
  - 섹션 타이틀(볼드) "응원 메시지 남기기"
  - 이름 필드: label "이름" + 우측 안내 "선택 · 비우면 익명", placeholder "익명"
  - 메시지 필드: label "응원 한마디" + 우측 글자수 카운터 "0/300" (최대 300자), placeholder "따뜻한 한마디를 남겨주세요..."
  - 등록 버튼
- **메시지 월 섹션**:
  - 좌측 라벨 "TO. 전승기 강사님께"
  - 섹션 타이틀(볼드) "도착한 마음들"
  - 우측 카운트 뱃지 "N개의 마음" (N = 현재 메시지 수)
  - 카드 그리드(반응형 2~3열, 모바일 1열). 각 카드: 메시지 텍스트 + 점선 구분선 + "from. 이름"(좌) / 날짜(우)
- **빈 상태**: 메시지가 하나도 없을 때 "첫 메시지를 남겨보세요" 안내 문구

## 비주얼 디자인
레퍼런스: 블랙+크림 에디토리얼 톤 (프레젠테이션 커버 슬라이드 느낌)

- **배경**: 크림/오프화이트 (`#F3EEE4` 톤)
- **텍스트/보더**: 블랙 (`#111` 근접) — 별도 포인트 컬러 없이 흑백 대비로만 구성
- **프레임**: 컨텐츠 영역을 두꺼운 블랙 보더(2~3px)로 감싸는 카드형 구조. 입력 폼 카드·메시지 카드 모두 동일한 블랙 보더 스타일 적용
- **메시지 카드**: 찢어진 종이(torn paper) 실루엣 — `clip-path` 지그재그 윗/아랫단으로 종이를 뜯어낸 듯한 형태 표현, 뒤에 블랙 레이어를 살짝 크게 깔아 종이 테두리처럼 보이게 처리(그림자 남용 없이 윤곽선 역할). 배경은 크림 단색 통일(레퍼런스의 핑크 배경·나비/반짝이 낙서·랜덤 컬러는 채택 안 함 — 블랙+크림 톤 유지가 우선). from/날짜는 점선 구분선으로 구획
- **타이포그래피**: [Pretendard](https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css) (CDN, 한/영 혼용 대응 가능한 기하학적 산세리프 — 레퍼런스의 굵은 그로테스크 느낌과 가장 가까움). 헤드라인 Bold(700), 서브텍스트/본문 Regular(400)~Medium(500) — 굵기 대비로 위계 표현. 장식적 서체·이모지·system-ui 기본 폰트 사용 안 함
- **상단 메타 바**: 레퍼런스의 "DATE / LABEL / NAME" 얇은 바 형태를 헤더 상단에 차용 — 예: 좌측에 날짜 또는 "축하 메시지", 우측에 "전승기 강사님" 같은 라벨
- **톤**: 장식 최소화, 여백과 보더 라인만으로 구조를 표현하는 절제된 에디토리얼 스타일 (파스텔·그라데이션·그림자·이모지·손글씨체 지양)

## 인터랙션 상태
| 상황 | 화면 반응 |
|---|---|
| 등록 버튼 클릭(저장 중) | 버튼 텍스트 "등록 중..."으로 변경 + 비활성화 (중복 제출 방지) |
| 등록 성공 | 폼 초기화 + 새 카드가 메시지 월 상단에 fade-in |
| 최초 페이지 로딩(메시지 조회 중) | 카드 자리에 스켈레톤 플레이스홀더 3개 표시 |
| 메시지 0개 | "첫 메시지를 남겨보세요" 빈 상태 문구 |

## 반응형 & 접근성
- **브레이크포인트**: 모바일(<640px) 카드 1열, 태블릿(640~1024px) 2열, 데스크톱(>1024px) 3열
- **터치 타겟**: 버튼·입력창 높이 최소 44px
- **입력 폰트 크기**: 모바일 자동 확대(zoom) 방지 위해 input/textarea `font-size` 16px 이상
- **포커스 표시**: 블랙 보더 톤에 맞춰 탭 이동 시 명확한 포커스 아웃라인(2px solid) 유지 — 제거 금지
- **대비**: 블랙 텍스트 on 크림 배경으로 WCAG AA 기준(4.5:1) 자연 충족
- **라벨**: 이름/메시지 입력창은 placeholder가 아닌 실제 `<label>` 사용 (플레이스홀더만으로 라벨 대체 금지)

## 에러 처리
- 메시지가 빈 값이면 등록 버튼 클릭 시 제출 차단 + 인라인 안내
- 메시지는 최대 300자 — textarea `maxlength=300` + 실시간 글자수 카운터로 초과 입력 자체를 막음
- 이름은 최대 20자 — 긴 이름이 카드 레이아웃을 깨지 않도록 `maxlength=20`
- Supabase 연결/insert 실패 시 화면에 에러 메시지 노출 (예: "메시지 등록에 실패했습니다. 다시 시도해주세요.")
- 최초 조회 실패 시(네트워크 문제 등) 안내 문구 표시

## 테스트 방법
- 로컬에서 `index.html` 직접 열어 등록 → 새로고침 → 메시지 유지 확인
- 두 개의 브라우저 탭(또는 다른 브라우저)에서 각각 열어, 한쪽에서 등록한 메시지가 다른 쪽 새로고침 후 보이는지 확인 (공유 시나리오 검증)
- 이름 비운 채 등록 시 "익명"으로 표시되는지 확인
- 빈 메시지로 등록 시도 시 차단되는지 확인

## 배포 및 설치
- 순수 정적 파일(서버·env 불필요, Supabase URL/anon key는 공개 가능한 클라이언트 키라 코드에 직접 포함)이므로 Netlify Drop(`netlify.com/drop`)에 `rolling-paper/` 폴더를 드래그하는 것만으로 배포 가능
- 폰 홈 화면에 "앱처럼" 설치(주소창 없이 열림)되도록:
  - `manifest.json` 추가 (`display: standalone`, `name`, `start_url`, 기본 아이콘)
  - `index.html`에 `apple-mobile-web-app-capable`, `apple-touch-icon`, `theme-color` 메타태그 추가 (iOS 홈 화면 추가 대응)
  - 커스텀 아이콘 이미지는 비주얼 디자인(컬러) 확정 후 제작 — v1은 브라우저 기본 아이콘으로 설치 가능한 상태만 보장

## 범위 밖 (v1 제외)
- 실시간 푸시 동기화
- 메시지 삭제/수정, 관리자 화면
- 로그인/인증
- 카드 배경색 랜덤화 등 장식 옵션 (필요 시 추후 추가)
