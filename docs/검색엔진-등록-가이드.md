## 1단계 — 구글 색인 문제 해결 (소유권 인증은 이미 완료)

### 1-0. 색인 커버리지 진단 결과 (2026-07-27 기준)

| 사유 | 페이지 | 판정 |
|---|---|---|
| **발견됨 - 현재 색인이 생성되지 않음** | **82** | ⚠️ 핵심 문제 |
| 적절한 표준 태그가 포함된 대체 페이지 | 11 | ✅ 정상 (다국어 canonical) |
| 리디렉션이 포함된 페이지 | 7 | ✅ 정상 (non-www → www) |
| 찾을 수 없음(404) | 3 | ⚠️ URL 확인 필요 |
| 크롤링됨 - 현재 색인이 생성되지 않음 | 3 | 대기 중 |
| 중복 페이지, Google에서 다른 표준 선택 | 2 | 확인 필요 |

**"발견됨 - 색인 생성 안 됨"** = 구글이 사이트맵에서 URL은 찾았지만 **크롤링을 미루고 있다**는 뜻.
사이트맵이 잘못돼서가 아니라, 구글이 이 사이트에 배정한 **크롤링 예산이 적어서** 생기는 현상.

원인 3가지:

1. **사이트맵 `lastmod`가 매 배포마다 전부 갱신됨**
   → 구글이 사이트맵 신호를 노이즈로 판단. **→ 코드에서 수정 완료**
2. **5개 언어판이 서로 hreflang로 묶여 있지 않음**
   → 88개 페이지가 서로 유사 문서로 보임. **→ 사이트맵 `xhtml:link`로 수정 완료**
3. **도메인 신뢰도(외부 링크) 부족**
   → 코드로 해결 불가. 아래 1-4 참고.

### 1-1. 사이트맵 제출 확인
좌측 메뉴 **색인생성 → Sitemaps**

- 목록에 `sitemap.xml` 이 **"성공"** 으로 있으면 → 1-2로
- 없으면 → "새 사이트맵 추가" 칸에 `sitemap.xml` 입력 후 제출

제출 몇 시간 뒤 **검색된 URL 110** 으로 뜨면 정상.

### 1-2. 404 3건 원인 찾기
**색인생성 → 페이지 → "찾을 수 없음(404)"** 행 클릭 → URL 3개 확인.

사이트맵의 22개 경로는 전부 200 OK로 확인됐으므로,
이 404는 **사이트맵 밖의 옛날 URL** (예전 구조에서 남은 링크)일 가능성이 높다.
URL을 알려주면 홈이나 적절한 페이지로 301 리다이렉트 처리.

### 1-3. 핵심 페이지 색인 요청 (수동 재촉)
PR 배포가 끝난 **뒤에** 할 것. 맨 위 검색창(URL 검사)에 하나씩 넣고
**"색인 생성 요청"** 클릭. 하루 10개 정도가 한도이니 중요한 것부터:

1. `https://www.yukjeup.com/`
2. `https://www.yukjeup.com/menu`
3. `https://www.yukjeup.com/locations/yangjae`
4. `https://www.yukjeup.com/locations/euljiro`
5. `https://www.yukjeup.com/yangjae-matjip`
6. `https://www.yukjeup.com/euljiro-matjip`
7. `https://www.yukjeup.com/dongdaemun-matjip`
8. `https://www.yukjeup.com/faq`

색인은 보통 **2~14일** 걸림.

### 1-4. 크롤링 예산 늘리기 = 외부 링크 (제일 효과 큼)
"발견됨-색인 안 됨" 82건을 실제로 뚫는 가장 강한 방법.
이미 있는 채널에 홈페이지 링크만 걸면 된다. 비용 0원.

- [ ] 인스타그램 프로필 링크 → `https://www.yukjeup.com`
- [ ] 네이버 스마트플레이스 (양재·을지로 둘 다) 홈페이지 항목
- [ ] 캐치테이블 매장 소개란
- [ ] 다이닝코드 / 식신 등 등록된 맛집 플랫폼 프로필
- [ ] 카카오 채널 프로필
- [ ] 유튜브 채널 링크란

### 1-5. 다국어는 욕심내지 말 것
22페이지 × 5개 언어 = 110개를 전부 색인시키려는 게 82건 적체의 배경이기도 하다.
당분간은 **한국어 22개 + 영어 22개**가 색인되는 데 집중하고,
일본어·중국어·베트남어는 그 다음. (사이트맵에서 빼라는 뜻은 아니고, 색인 요청 우선순위 얘기.)

## 2단계 — 네이버 서치어드바이저 등록

메타태그는 이미 사이트에 박혀 있음
(`naver-site-verification` = `08823a1f...`).
등록을 하다 만 상태일 수 있으니 **먼저 로그인해서 확인**부터.

### 2-1. 접속
https://searchadvisor.naver.com → **웹마스터도구** → 네이버 계정 로그인

### 2-2. 사이트 등록 확인
- 이미 `https://www.yukjeup.com` 이 목록에 있으면 → 2-4로 건너뜀
- 없으면 → 입력창에 `https://www.yukjeup.com` 넣고 등록

### 2-3. 소유확인
"HTML 태그" 방식 선택 → 화면에 나오는 `content` 값이
**`08823a1fd3a76a7be6f8bf049777f51dfe28e9a1` 과 같은지 확인**

- 같으면 → 바로 **소유확인** 버튼 클릭 (이미 사이트에 있으니 통과)
- 다르면 → 새 값을 알려주면 교체해서 배포

### 2-4. robots.txt 확인
좌측 **검증 → robots.txt** → "수집 요청" 클릭
`Yeti`(네이버 봇) 허용으로 나오면 정상.

### 2-5. 사이트맵 제출
좌측 **요청 → 사이트맵 제출**

입력:
```
https://www.yukjeup.com/sitemap.xml
```
(네이버는 구글과 달리 **전체 주소**를 넣어야 함)

### 2-6. 웹페이지 수집 요청
좌측 **요청 → 웹페이지 수집**
1단계 1-3의 URL 목록을 하루 몇 개씩 나눠서 넣기. (하루 50개 한도)

### 2-7. 사이트 최적화 점검
좌측 **검증 → 사이트 최적화** 실행 → 빨간 항목 있으면 캡처해서 알려주기.

## 3단계 — 네이버는 "플레이스"가 진짜 승부처

네이버 검색에서 음식점은 홈페이지보다 **네이버 플레이스**가 먼저 뜸.
서치어드바이저는 홈페이지용이고, 아래는 별개로 관리해야 함.

- 네이버 플레이스 (양재역점): place ID `1672141709`
- 네이버 플레이스 (더룸 을지로동대문점): place ID `2033717879`

체크할 것:
- [ ] 스마트플레이스 관리자에서 **홈페이지 링크에 `https://www.yukjeup.com` 등록** (1-4와 동일)
- [ ] 상호·주소·전화번호가 홈페이지와 **글자 하나까지 동일**한지 (NAP 일관성)
- [ ] 대표 키워드 등록: `양재역 고기집`, `양재역 삼겹살`, `을지로 맛집`, `동대문 고기집`
- [ ] 사진 30장 이상 / 메뉴판 최신화
- [ ] 리뷰 답글 100% 달기

## 4단계 — 측정 도구 붙이기 (선택, 하지만 권장)

지금 GA4·네이버 애널리틱스 스크립트가 **코드에는 있는데 환경변수가 비어서 안 붙고 있음.**
넣으면 "어떤 키워드로 몇 명 들어왔는지"가 보임.

Vercel → Settings → Environment Variables 에 추가 후 재배포:

| 이름 | 값 |
|---|---|
| `NEXT_PUBLIC_GA_ID` | GA4 측정 ID (`G-XXXXXXXXXX`) |
| `NEXT_PUBLIC_NAVER_ACCOUNT_ID` | 네이버 애널리틱스 인증 ID |

GA4 ID는 https://analytics.google.com 에서 속성 만들면 나옴.
네이버 애널리틱스는 https://analytics.naver.com 에서 발급.

서치콘솔 **설정 → 연결**에서 GA4 속성을 연결해두면 두 데이터가 합쳐져서 보기 편함.

## 이번에 코드에서 고친 것

| 파일 | 내용 |
|---|---|
| `src/app/sitemap.ts` | 사이트맵에 hreflang 대체본 추가 (5개 언어판이 중복 콘텐츠로 안 잡히게) |
| `src/app/sitemap.ts` | `lastmod`를 빌드시각 → 고정 날짜로. 무관한 배포마다 110개 URL이 전부 "수정됨"으로 찍혀 구글이 lastmod를 무시하던 문제 |
| `src/app/robots.ts` | `/admin`, `/login`, `/api/` 크롤 차단 + `Host` 지시자 추가 |
| `src/lib/constants/brand.ts` | 환경변수 누락 시 vercel 미리보기 주소가 새어나가던 폴백 → `https://www.yukjeup.com` |

> 📌 `sitemap.ts`의 `LAST_MODIFIED` 상수는 **콘텐츠를 실제로 고쳤을 때만** 날짜를 갱신할 것.
> 배포할 때마다 자동으로 바뀌면 이번에 고친 게 원상복구된다.
