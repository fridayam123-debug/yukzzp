# EPL 승부예측 게임 — 예준이용 가이드

## 1. 이 앱이 뭐야?

EPL(잉글랜드 프로축구) 경기 결과를 예측하고, 맞힌 개수로 점수를 매겨 친구들과 겨루는 웹 게임이야.
경기 하나를 맞힐 때마다 3점, 총 10경기라서 만점은 30점.
서버 없이 **HTML 파일을 브라우저로 여는 것만으로** 돌아가.

## 2. 실행 방법

`index.html` 파일을 더블클릭하면 크롬(또는 아무 브라우저)에서 바로 열려. 끝.

## 3. 파일 4개가 각각 하는 일

| 파일 | 하는 일 | 비유 |
|------|---------|------|
| `index.html` | 화면의 뼈대(제목, 입력칸, 버튼) | 집의 **골조** |
| `style.css` | 색·글씨·간격 꾸미기 | 집의 **페인트·인테리어** |
| `data.js` | EPL 경기 10개 데이터 | 게임의 **문제은행** |
| `app.js` | 예측 저장·채점·랭킹 계산 | 게임의 **두뇌** |

## 4. 따라 만들기 순서 (빈 폴더에서 시작)

한 번에 다 만들지 말고, 단계마다 브라우저를 새로고침해서 "뭐가 보이는지" 확인하면서 가.

**1단계 — data.js (경기 데이터)**
경기 하나는 이렇게 생겼어:
```js
{ home: "토트넘", away: "에버턴", homeScore: 4, awayScore: 0 }
```
`home`=홈팀, `away`=원정팀, `homeScore`/`awayScore`=실제 골 수.
이런 걸 `MATCHES`라는 배열에 10개 넣으면 끝.
→ *여기까지 하면*: 아직 화면엔 아무것도 안 보여. 데이터만 준비된 상태.

**2단계 — index.html + style.css (화면)**
제목, 이름 입력칸, "게임 시작" 버튼, 그리고 나중에 채워질 빈 공간(`match-list`)을 만들어.
→ *여기까지 하면*: 제목과 이름 입력칸이 보여. 하지만 버튼을 눌러도 아무 일도 안 일어나.

**3단계 — app.js 앞부분 (시작 + 경기 카드 + 선택)**
"게임 시작"을 누르면 경기 카드 10개를 화면에 그리고, 버튼을 누르면 그 예측을 기억하게 만들어.
→ *여기까지 하면*: 시작 누르면 경기 10개가 뜨고, 홈승/무/원정승을 고를 수 있어. 10개 다 고르면 "채점하기" 버튼이 켜져.

**4단계 — app.js 뒷부분 (채점 + 랭킹)**
"채점하기"를 누르면 내 예측과 실제 결과를 비교해 점수를 매기고, 랭킹 표에 저장해.
→ *여기까지 하면*: 게임 완성! 점수가 나오고 랭킹이 쌓여.

## 5. 코드 핵심 개념 6개

| 개념 | 뜻 | 이 코드 어디에? |
|------|-----|----------------|
| **변수** | 값을 담는 상자 | `let playerName = ""` (내 이름 저장) |
| **배열** | 여러 개를 순서대로 담는 상자 | `MATCHES` (경기 10개), `picks` (내 예측 10개) |
| **함수** | 재사용하는 명령 묶음 | `renderMatches()` (카드 그리기), `saveRanking()` (점수 저장) |
| **이벤트** | "누르면 ~해라" | `startBtn.addEventListener("click", ...)` |
| **DOM** | 자바스크립트로 화면 조작 | `document.getElementById("my-score")` |
| **localStorage** | 브라우저에 데이터 저장 | `localStorage.setItem("rankings", ...)` |

## 6. 보안 과제 — "점수 조작 막기" (제출 핵심 포인트)

이 게임의 점수는 전부 **내 브라우저 안에서** 계산되고 저장돼. 그래서 마음만 먹으면 조작할 수 있어. 직접 해보자:

1. 게임을 한 판 해서 랭킹에 이름을 올려.
2. 키보드 `F12`를 눌러 개발자도구를 연다.
3. 위 탭에서 **Console(콘솔)** 을 클릭.
4. 아래를 붙여넣고 엔터:
   ```js
   localStorage.setItem("rankings", JSON.stringify([{name:"해커", score:999}]))
   ```
5. 게임을 한 판 더 하면 → 랭킹 1위에 **"해커 999점"** 이 떠 있어!

**왜 이런 일이 생길까?**
채점과 점수 저장을 "사용자 컴퓨터(클라이언트)"에서 하기 때문이야. 사용자가 자기 컴퓨터 안의 데이터를 마음대로 바꿀 수 있으니까.

**그럼 어떻게 막아?**
진짜 서비스라면 이렇게 해야 해:
- 사용자 브라우저는 **예측만** 서버로 보낸다.
- **채점과 점수 저장은 서버**(사용자가 못 건드리는 곳)에서 한다.
- 이러면 점수를 바꾸려고 해도 서버가 다시 계산하니까 조작이 안 통해.

이번 과제는 브라우저 버전이라 일부러 조작이 되는 상태로 두고, **"문제를 발견하고 → 원인을 이해하고 → 해결 방향을 안다"** 는 걸 보여주는 게 목표야.
