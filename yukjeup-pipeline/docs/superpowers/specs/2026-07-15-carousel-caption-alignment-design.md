# 2026-07-15 캐러셀·캡션 정합화 디자인

## 목표

선택된 SEO·GEO·AEO 캡션과 2026-07-15 캐러셀의 핵심 질문을 같은 표현으로 통일하고, 캡션에만 있던 브랜드 증거를 이미지에도 담는다. 기존 V2 원칙인 “슬라이드는 포스터, 상세 설명은 캡션”은 유지한다.

## 결정

기존 7장을 8장으로 확장한다. 현재 엔드 카드 앞에 ‘맛의 근거’ 슬라이드를 추가한다. 기존 슬라이드에 증거 문구를 분산하거나 엔드 카드에 몰아넣지 않는다.

## 슬라이드 구성

1. **커버**: `회식 장소, 이 3개만 보면 실패 안 합니다`와 `총무의 3초 점검` 유지. 페이지 도트는 8개로 변경.
2. **인트로**: `답은 세 가지입니다`를 중심으로 `연기 · 굽기 · 룸`을 제시한다.
3. **체크 1**: 질문을 `① 연기, 아래로 빠지나요?`로 통일. 답은 `하향식 덕트`.
4. **체크 2**: 질문을 `② 고기는 누가 굽나요?`로 통일. 답은 `전담 서버 그릴링`.
5. **체크 3**: 질문을 `③ 인원에 맞는 룸이 있나요?`로 통일. 답은 `4~40인 룸`.
6. **저장 앵커**: 위 세 질문을 동일한 표현으로 반복한다. 캡션의 `6번째 장` 지목과 일치시킨다.
7. **맛의 근거**: `맛의 근거도 있습니다`를 헤드라인으로 사용한다. `산청 흑돼지 · 특허 파동숙성`, `정육왕 블라인드 테스트 — 한국 5대 프리미엄 돼지 중 밸런스 1위`, `이원일 셰프 · 211TV 소개`를 두 개 이하의 짧은 증거 블록으로 조판한다.
8. **엔드**: CTA를 `6번째 장을 지금 저장해두세요`로 통일하고 계정명과 지점명을 유지한다.

모든 페이지 인덱스는 `/08`로 변경한다.

## 사진과 레이아웃

- 01~06의 사진과 크롭은 유지한다.
- 07 증거 슬라이드는 현재 S급 `yukjeup-menu-04.jpg`를 사용한다.
- 08 엔드는 S급 `yukjeup-menu-05.jpg`를 사용해 07과 시각적으로 구분한다.
- 텍스트 존 그라디언트만 사용하고 전면 균일 딤은 추가하지 않는다.
- Fraunces와 Pretendard만 사용하며, 80px 안전 여백과 하단 120px 보호영역을 유지한다.

## 소스 변경

- `output/2026-07-15/05_caption.md`: 사용자가 선택한 캡션으로 확정한다.

## 렌더링과 검증

1. Playwright에서 `deviceScaleFactor: 1`과 1080×1440 뷰포트를 사용한다.
2. Fraunces·Pretendard 로딩 후 각 `.slide`를 개별 PNG로 저장한다.
3. 8개 PNG의 해상도, 텍스트 캔버스 이탈, 80px 안전 여백, 하단 120px 보호영역을 자동 검사한다.
4. 01~08을 모두 열어 잘림, 대비, 사진 중심부 밝기, 문구 정합성을 눈으로 확인한다.
5. 브라우저 콘솔 오류나 이미지·폰트 요청 실패가 있으면 결과를 확정하지 않는다.
